# Get lengths of brobs and glubs

Get lengths of brob and glub vectors

## Usage

``` r
# S4 method for class 'brob'
length(x)
# S4 method for class 'glub'
length(x)
```

## Arguments

- x:

  vector of class brob or glub

## Author

Robin K. S. Hankin

## Examples

``` r
x <- as.brob(-10:10)
length(x)
#> [1] 21
```
